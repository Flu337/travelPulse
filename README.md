# TravelPulse

Клиентская часть веб-приложения **TravelPulse** для планирования походов и путешествий. Приложение объединяет основные инструменты подготовки поездки на одной платформе и подходит как новичкам, так и опытным путешественникам и организаторам групп.

## Стек технологий

- **Nuxt 3** — фреймворк на базе Vue 3
- **Vue 3** (Composition API, `<script setup>`)
- **TypeScript** — типизация состояний и композаблов
- **CSS3** (Flexbox, CSS Grid, CSS-переменные) — отдельные таблицы стилей для каждого компонента
- **Google Fonts (Inter)** — основная типографика по макету Figma

## Реализованный функционал

- **Шапка сайта и мультиязычность**: логотип, строка быстрого поиска на десктопе, выпадающее переключение языка (`RUS` / `ENG` / `中国人`) с динамическим переводом интерфейса, кнопка входа и меню.
- **Интерактивный поиск поездок**:
  - переключение категорий: «Прокат автомобилей», «Авиабилеты», «Отели»;
  - выбор точки отправления (`Откуда`) из списка городов и аэропортов;
  - выбор направления (`Куда`) с быстрыми действиями «Поиск везде» и «Поиск сложного маршрута»;
  - интерактивный календарь выбора дат (`Туда` / `Обратно`) с переключением режимов («Конкретные даты» / «Гибкие даты»), типа поездки («Туда-обратно» / «В одну сторону») и перелистыванием месяцев;
  - счётчик путешественников (взрослые и дети);
  - выбор класса обслуживания («Эконом», «Премиум - эконом», «Бизнес - класс», «Первый - класс»).
- **Авторизация и регистрация**: 3 последовательных модальных окна — выбор способа входа (Email, Facebook, Google, Apple), форма входа по почте и паролю, форма регистрации с подтверждением пароля и принятием условий.
- **Контентные секции**:
  - блок популярных направлений (4 карточки на десктопе и интерактивный слайдер по 2 карточки на мобильных устройствах);
  - сетка карточек популярных туров с фотографиями, описанием и рейтингом;
  - секция планирования поездки с вкладками (`Регион`, `Страна`, `Аэропорт`, `Город`) и ссылками на направления;
  - подвал сайта с навигацией, выбором региона/валюты и копирайтом.
- **Адаптивная вёрстка**: полная адаптация под десктоп, планшеты и мобильные экраны (включая отдельную мобильную форму поиска и компактную раскладку по мобильному макету).

## Требования

- **Node.js** версии 18.x или выше
- **npm** (или совместимый менеджер пакетов: pnpm / yarn)

## Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:3000`.

## Сборка для продакшена

```bash
# сборка приложения
npm run build

# локальный предпросмотр собранной версии
npm run preview

# генерация статического сайта
npm run generate
```
